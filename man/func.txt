{yellow}NAME{reset}
    {cyan}func{reset} - cSH Command Line Package Manager for Windows

{yellow}SYNOPSIS{reset}
    {cyan}func{reset} [{cyan}command{reset}] [{green}options / package_name{reset}]

{yellow}DESCRIPTION{reset}
    {cyan}func{reset} is a lightweight, recursive package manager built natively for 
    Windows batch script environments. It connects to raw GitHub repositories or 
    local directories to safely download, upgrade, and track system utility commands 
    while natively handling dependencies and configuration caching.

{yellow}COMMANDS{reset}
    {cyan}update{reset}
        Fetches the latest package indexes from all configured remote and local 
        repositories and overwrites the active cache files. Always run this 
        before modifying or installing packages.

    {cyan}list{reset} [{green}--installed{reset}]
        By default, lists all available packages found inside your cached repository 
        indexes. Add the {green}--installed{reset} flag to cleanly display the `.cmd` utility 
        packages currently sitting active on your local system directory.

    {cyan}search{reset} {green}<keyword>{reset}
        Queries all repository indexes looking for matches inside package names, 
        versions, or descriptions. 

    {cyan}install{reset} {green}<package_name>{reset}
        Locates the specified package from your cache files, automatically parses 
        and recursively handles any listed upstream dependencies, and pulls the raw 
        source script down using an optimized `curl` routine.

    {cyan}uninstall{reset} {green}<package_name>{reset}
        Removes a command script entirely from your local executable environment. 
        {gray}Alias: remove{reset}

    {cyan}full-upgrade{reset}
        Loops through your entire folder of custom commands and cleanly re-downloads 
        the latest version of every single package directly from the repo caches. 
        {gray}Alias: upgrade{reset}

    {cyan}add-repo{reset} {green}<url>{reset}
        Appends a brand new GitHub Raw repository root URL or path string directly 
        into your active package router config. 
        {gray}Alias: addrepo{reset}

    {cyan}remove-repo{reset} {green}<url>{reset}
        Removes an active package repository string definition out of your config 
        environment seamlessly.
        {gray}Alias: removerepo{reset}

    {cyan}remake-config{reset}
        Resets and re-initializes your `.config\funcpath` mapping file completely 
        back to its default state.
        {gray}Alias: remake{reset}

    {cyan}help{reset} [{green}command{reset}]
        Displays main routing context guidelines, or passes specialized arguments 
        on specialized usage rules for single parameters.
        {gray}Flags: -h, --help{reset}

{yellow}ENVIRONMENT PATHS{reset}
    All persistent information is generated relative to the script runtime directory:
      - {magenta}Config File{reset}:  `..\.config\funcpath`
      - {magenta}Cache Storage{reset}: `..\.config\saved\`
      - {magenta}Binary Folder{reset}: Identical path location to `func.cmd`

{yellow}TIPS & TROUBLESHOOTING{reset}
    - If your commands throw an execution error, make sure to execute {cyan}func update{reset} 
      to re-cache package headers before building.
    - If you are trying out an editor like {green}ed-dev{reset}, keep in mind it has a dependency 
      on {green}cat{reset}, which `func` will automatically pull down for you during installation!
