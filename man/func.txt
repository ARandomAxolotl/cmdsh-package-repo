NAME
    func - Package manager for cSH functions.

SYNOPSIS
    func [command] [target] [options]

    Commands: install | uninstall | list | update | full-upgrade | 
              search | add-repo | remove-repo | remake-config | help

COMMANDS
    install <pkg>       Resolves dependencies and installs the specified package[cite: 40].
    uninstall <pkg>     Removes an installed package from your local system[cite: 40].
                        (Alias: remove)
    list                Lists all available packages in the cached repositories[cite: 41].
    list --installed    Lists only the packages currently installed on your system[cite: 41].
    update              Refreshes the local repository indexes by fetching the latest data[cite: 42].
                        (Alias: update-source)
    full-upgrade        Checks all installed packages and re-downloads them to ensure 
                        they are on the latest cached versions.
                        (Alias: upgrade)
    search <keyword>    Searches cached repositories for a specific term in names or descriptions[cite: 42].
    add-repo <url>      Adds a new repository URL to your configuration file.
                        (Alias: addrepo)
    remove-repo <url>   Removes a specified repository URL from your configuration file.
                        (Alias: removerepo)
    remake-config       Resets the configuration file to the default repository list. 
                        (Alias: remake)
    help [command]      Displays the general help menu or detailed usage for a specific command.

OPTIONS
    -h, --help          Can be appended to any command to display specific usage instructions 
                        (e.g., `func install --help`).
