{yellow}NAME{reset}
    {cyan}apt{reset} - A winget wrapper with Debian-like syntax.

{yellow}SYNOPSIS{reset}
    {cyan}apt{reset} [{cyan}command{reset}] {green}<package>{reset}

{yellow}COMMANDS{reset}
    {cyan}install{reset} {green}<pkg>{reset}   Installs the specified package via winget.
    {cyan}update{reset}          Lists available upgrades for all installed packages.
    {cyan}upgrade{reset} {green}<pkg>{reset}   Upgrades a specific package to the latest version.
    {cyan}search{reset} {green}<pkg>{reset}    Searches the winget repository for a package.

{yellow}DESCRIPTION{reset}
    Provides a familiar interface for users coming from Debian-based 
    systems to manage Windows applications.
