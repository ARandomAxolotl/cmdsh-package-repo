NAME
    scmdc - Secure CMD Compiler.

SYNOPSIS
    scmdc [-s] [-d] [-v] [-b] <filename>

OPTIONS
    -s    Silent mode; suppresses output.
    -d    Debug mode; shows line-by-line processing.
    -v    Verbose mode; turns on echo.
    -b    Battery/Bat mode; processes .sbat into .bat files.

DESCRIPTION
    Compiles .scmd files into .cmd. It checks for "suspect" commands 
    and paths defined in the config, disabling any blocked lines 
    it encounters.
